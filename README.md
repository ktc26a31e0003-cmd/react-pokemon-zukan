# React ポケモン図鑑

ポケモンAPIを使ったReact + TypeScript製のポケモン図鑑です。

## 使用技術

- React / TypeScript
- Vite
- React Router（HashRouter）
- TanStack Query
- Tailwind CSS
- GitHub Actions / GitHub Pages

## 起動方法

```bash
npm install
npm run dev
```
